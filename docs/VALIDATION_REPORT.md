# Проверка alpha-прототипа — 28 октября 2026

Проект остаётся частичным прототипом: весь исходный объём ТЗ ещё не реализован.

## Реально выполнено

- Установлены Eclipse Temurin JDK 17.0.17+10 и официальный Gradle 8.8 с проверкой опубликованных SHA-256.
- `python scripts/test_core.py`: 43 проверки прошли.
- `gradle build`: BUILD SUCCESSFUL, включая reobfJar, coreTest и commandTreeTest.
- commandTreeTest проверяет корневые команды, восемь исполняемых путей и отсутствие неправильной вложенности под credit/cityhall.
- Стандартная задача test не содержит JUnit-тестов. Значимые проверки выполняются отдельными JavaExec-задачами, подключёнными к check.
- Разобраны 15 JSON-документов ресурсов.
- Клиент Forge 47.4.28 / Minecraft 1.20.1 дошёл до главного меню в Xvfb с Mesa llvmpipe OpenGL 4.5. Первый запуск без зависимости штатно закрыт.
- Совместный dev-запуск с Upgrader Items 1.2.1 дошёл до меню и подключился к выделенному серверу. GUI смартфона открылся, текстуры монеты и смартфона отобразились.
- Выделенный сервер с обоими модами создал тестовый мир, достиг Done, принял dev-клиент и выполнил команды UDE.
- Игровой сценарий: открыть счёт; выдать 1000; снять 3 монеты; внести 2; получить кредит 500 с долгом 575; погасить 100. Результат: баланс 1300, долг 475, одна физическая монета.
- Внесение двух монет при наличии одной отклонено без изменения баланса и инвентаря.
- После save-all flush, полной остановки и нового запуска сервера значения 1300/475 и инвентарь восстановлены.

## Исправлено

- Скобки дерева Brigadier: корневые ветви больше не вложены в credit, cityhall или результат регистрации dispatcher.
- Обработка checked-исключений CommandSyntaxException из player-команд.
- Вызов хранилища SavedData приведён к API Minecraft 1.20.1.
- Добавлен используемый обработчиком сервера фильтр доступности отправки коллекторов. Недоступный игрок не теряет отложенную отправку; поведение проверяется после сериализации ядра.

## Upgrader Items

Официальный файл версии Modrinth nIG81STn проверен по SHA-512. Метаданные: Forge, Minecraft 1.20.1, mod ID upgrader, версия 1.2.1.

Через javap -public подтверждены методы net.execheinz.upgrader.value.ItemValues.unitValue(Level, Item) и stackValue(Level, ItemStack). UDE пока использует прежний fallback; настоящий адаптер ещё не реализован.

Production-JAR нельзя напрямую класть в run/mods dev-среды: это вызвало NoSuchFieldError: f_279569_. Подключение через fg.deobf в локальном Gradle init script устранило ошибку. Чужой JAR не включён в UDE и архив исходников.

## Ограничения

- Minecraft GameTests отсутствуют: не запускались и не считаются пройденными.
- Не проверены автоматическая генерация мэрии, весь бизнес-цикл, коллекторский AI, защита хранилища и одновременные операции нескольких игроков.
- GUI проверен только в объёме существующего простого смартфона. Полноценные приложения и сетевые меню ещё не реализованы.
- Звук проверялся через OpenAL No Output; слышимое воспроизведение не проверено.
- Внешняя проверка ключей Yggdrasil выдаёт Connection refused. Локальный тест выполнялся в отдельном мире с server-ip=127.0.0.1 и online-mode=false. Публичный сервер и авторизация Microsoft не проверялись.
- Upgrader Items пишет сообщения об отсутствующем minVersion в собственных mixin-конфигах; после dev-remap это не помешало запуску и игре.
- В компиляции остаются предупреждения об устаревающих API Forge.
